# Subtraction design — direção da reformulação

## Princípio

A versão anterior tinha conteúdo forte, mas colocava uma experiência 3D, um modal e diversas camadas editoriais entre o visitante e os projetos. A reformulação não tenta “simplificar a estética”; ela reduz decisões e passos necessários para entender quem é Matteo, o que ele construiu e como entrar em contato.

## O que foi preservado

- identidade `teo`;
- quatro projetos selecionados;
- imagens reais dos projetos;
- contexto, problema, decisão, estado atual, limite e próximo passo;
- links de código e sistemas publicados;
- currículo e e-mail;
- compatibilidade com GitHub Pages.

## O que foi removido

- caixa e pastas 3D;
- Three.js;
- interação de arrastar para abrir;
- modal de projeto;
- transições cenográficas;
- textura de papel;
- quatro famílias tipográficas;
- excesso de títulos, marcadores e chamadas repetidas.

## Nova hierarquia

1. disponibilidade e posicionamento;
2. projetos selecionados;
3. formação e forma de trabalhar;
4. contato.

## Sistema visual

- fundo grafite;
- texto marfim;
- linhas estruturais;
- violeta como único acento;
- Inter para leitura;
- IBM Plex Mono para metadados;
- sem gradientes, sombras decorativas ou cards genéricos.

## Interação

Os estudos de caso usam `details/summary`, mantendo o conteúdo no documento e permitindo leitura progressiva sem modal. O único comportamento adicional é a cópia do e-mail.
